# Contributing to ScholarLink

Thanks for helping. Fixes, training content, funding listings, translations and docs are all welcome.

1. Fork, branch from `main`, and keep each pull request to one change.
2. Run the site locally with `node dev.mjs` (http://localhost:8888, data in `local-data/`).
3. Training content lives in `public/training-data.js`; funding listings in `public/funding-data.js`.
